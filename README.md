# Portfolio

O meu portfólio pessoal, criado com React e Vite.

## Começar

```bash
npm install
npm run dev
```

Para criar a versão de produção:

```bash
npm run build
```

As páginas usam rotas por hash, por isso funcionam em alojamentos estáticos como GitHub Pages:

- `#/` — início
- `#/works` — trabalhos
- `#/contact` — contacto

## Estrutura

- `source/pages` — conteúdo de cada página
- `source/components` — componentes reutilizáveis
- `source/styles` — estilos globais
- `source/main.jsx` — ponto de entrada da aplicação
